Security posture

Fail closed is the starting point.

The production boundary is designed to reject undeclared traffic and constrain every request path while keeping tenants and credentials separated.

01
Identity firstEntra and Office SSO establish the primary identity path, with controlled delegated fallbacks where configured.
02
Exact-origin allowlistsOutbound destinations must match declared origins; redirects are not followed.
03
Tenant isolationTenant-aware policy and settings boundaries keep organizational state separated.
04
Bounded trafficRequest and response byte caps combine with rate limiting at the same-origin server boundary.
05
Supply-chain checksGitleaks scans for secrets, Trivy scans the container, and CI emits an SBOM.
06
Validated releasesTypecheck, unit tests, builds, manifest validation, and release gates must pass in CI.
